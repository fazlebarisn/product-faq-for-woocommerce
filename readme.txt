= 📖 Quick Start (Set Up in Under 60 Seconds) =

1. **Single Product FAQs**: Go to **Products ➔ All Products**, edit any product, open the **FAQ** tab in the **Product Data** panel, and type custom FAQs, pick an **Objection-Buster Template**, or click **"✨ Generate with AI"**.
2. **Bulk Category / Tag FAQs**: Go to **Product FAQ ➔ Bulk FAQ** to create category-wide or tag-wide FAQ groups that automatically apply to matching products.
3. **Gutenberg Block (`/faq`)**: In the WordPress Block Editor or Site Editor, type `/faq` and choose **Product FAQ Accordion**.
4. **Universal Shortcodes**:
   * `[woo_product_faq]` — Automatically renders the current product's FAQs on Single Product templates, or displays your Store/Bulk & Product FAQs on a standalone FAQ page.
   * `[woo_product_faq id="123" title="Product Questions"]` — Renders FAQs for a specific WooCommerce Product ID (`123`).
   * `[woo_product_faq category="hoodies"]` — Renders FAQs filtered to a specific WooCommerce Product Category slug or term ID.

== Installation ==

1. Install **Product FAQ for WooCommerce** via **Plugins ➔ Add New** in your WordPress dashboard, or upload the `product-faq-for-woocommerce` folder to `/wp-content/plugins/`.
2. Activate the plugin through the **Plugins** screen (requires **WooCommerce**).
3. *(Optional)* Visit **Product FAQ ➔ Settings** to adjust display position (*Product Tab* is active by default on new installs), customize colors/typography, or connect an AI provider via **Settings ➔ Connectors** (WordPress 7.0+).
4. Edit any WooCommerce product, open **Product Data ➔ FAQ**, add or generate your FAQs, and click **Update**!

== Frequently Asked Questions ==

= How many FAQs can I add per product in the Free version? =
**Unlimited!** Starting in version 1.7.0, there is no limit on how many single-product FAQs you can add manually or via templates. You can also generate up to **10 AI FAQs per batch** on individual products and create up to **3 Bulk Category/Tag FAQ groups** (5 FAQs per group) completely free.

= Do I need an AI API key to use this plugin? =
No! AI generation is 100% optional. You can write unlimited custom FAQs manually and use the built-in **1-Click Objection-Buster Templates** (*Shipping*, *Returns*, *Warranty*, *Sizing*, *Care*) right out of the box on any WordPress 5.0+ store without configuring any AI key.

= How does the AI FAQ Generator work? =
On WordPress 7.0+, Product FAQ integrates with WordPress's official native AI Client (**Settings ➔ Connectors**), supporting **Google Gemini, OpenAI, and Anthropic Claude** using your own direct API key (zero middleman subscription or token markups). When you click **"✨ Generate with AI"** on a product, the plugin enriches the prompt with your product's live WooCommerce price, stock status, weight, dimensions, categories, and attributes for accurate, factual answers.

= Will this plugin conflict with Bootstrap, Elementor, Flatsome, or Block Themes? =
No. All frontend CSS and JavaScript selectors are strictly scoped inside `.woo-faq-container` (with no generic `.container` or bare `.accordion` overrides), and assets are only enqueued on pages where FAQs are used. It works cleanly with Elementor, Divi, Bricks, Flatsome, WoodMart, Astra, Kadence, Storefront, and Full Site Editing (FSE) Block Themes.

= Can I add clickable links, bold text, and bullet lists inside FAQ answers? =
Yes! Both Single-Product FAQs and Bulk Category/Tag FAQs support rich HTML formatting (`<a href="...">`, `<strong>`, `<em>`, `<ul>`, `<ol>`, `<li>`) and multi-paragraph line breaks, while automatically stripping HTML tags inside the Google `FAQPage` JSON-LD schema so your structured data stays valid.

= How does priority work if a product has both Individual FAQs and Category Bulk FAQs? =
The plugin uses a smart **3-Tier Resolution Engine**:
1. If a product has **Individual Product FAQs**, those display first.
2. Otherwise, if the product belongs to a **Sub-Category** with a Bulk FAQ group, the Sub-Category FAQs display.
3. Otherwise, it falls back to **Main Category** or **Tag** Bulk FAQs.

= Can I back up or migrate my FAQ settings and Bulk FAQ groups? =
Yes! Go to **Product FAQ ➔ Settings ➔ 💾 Backup & Tools** to export your design settings and Bulk FAQ groups to a clean `.json` file and restore them on any staging or production store in 1 click.
